## 🎯 User Journey Example

**New Learner Path:**

1. **Lands on Cover** → Sees beautiful gradient page with stats
2. **Clicks "Start Learning"** → Reads guide, understands daily rhythm
3. **Clicks "Browse Lessons"** → Sees sidebar with all stages
4. **Clicks A0-A1** → Expands to show Weeks 1-10
5. **Clicks Week 1** → Sees all 6 day cards for Week 1
6. **Scrolls through Day 1** → Reads structured lesson plan
7. **Notes checkpoint** → Self-assesses at end of day
8. **Continues to Day 2** → Repeats for 600 days total
9. **Passes gates** → At Weeks 10, 22, 40, 58, 78, 100
10. **Reaches Week 100** → Completes C2/TOEFL peak training

**Total Learning Time:** ~900-1,200 hours over 100 weeks

## 🌟 Key Design Principles

1. **Readability First** - Comfortable typography, generous spacing
2. **Clear Hierarchy** - Headers, sections, visual separation
3. **Consistent Structure** - Every day follows same pattern
4. **Beautiful but Functional** - Aesthetics support usability
5. **Responsive** - Works seamlessly on any device
6. **Accessible** - Keyboard navigation, semantic HTML
7. **Fast** - Static files, no server processing
8. **Themeable** - Light/dark mode with persistence

---

## 🎓 Educational Design

Each daily card includes:
- **Time estimates** for each block
- **Clear goals** stated upfront
- **Structured progression** through 5 blocks
- **Self-assessment** checkpoint at end
- **Vocabulary in context** with examples
- **Grammar patterns** explicitly stated
- **Production tasks** (speak + write)
- **Review system** with Anki integration

This mirrors effective SRS (Spaced Repetition System) learning while maintaining engagement through variety.
