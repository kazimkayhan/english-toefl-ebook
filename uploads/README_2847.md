# English → TOEFL Daily Lesson Cards (A0 → C2 Peak)

A complete **100-week** daily curriculum (600 day cards) from absolute beginner (A0) to **C2 / TOEFL iBT peak**, aligned to the **2026 TOEFL iBT format** (from 21 January 2026) in the later weeks.

## How to use

1. Open `COMPLETE-A0-to-C2-daily-lesson-cards.md` (or the stage file for your level).
2. Do **one card per study day** (Day 1–6). Rest on Day 7 or use it only for light Anki.
3. Keep a **portfolio folder**: voice memos, writing samples, error log, Anki exports.
4. Pass **gates** at Weeks 10, 22, 40, 58, 78, 100 before accelerating.

## Daily rhythm (~90–120 min)

| Block | Time | Purpose |
|-------|------|---------|
| Warm-up | 10–15 min | Anki + activate + pronunciation |
| Learn | 25–35 min | Grammar point + concrete vocab + examples |
| Practice | 20–25 min | Controlled tasks |
| Produce | 20–25 min | Speak (voice memo) + Write (length target) |
| Review | 10–15 min | Anki cards for today + hardest sentence |

**Weekly load:** ~12 hours across 6 days. **Day 6** is heavier on review/integration.

## Resources (types — no required URLs)

- **Coursebook parallel:** any CEFR-leveled series unit matching the week grammar (A0–C1).
- **Anki / flashcards:** vocab + cloze grammar; tag `WeekW-DayD`.
- **Graded readers:** extensive reading 15–20 min on lighter days.
- **Pronunciation:** minimal pairs, shadowing, Listen and Repeat strings.
- **TOEFL (from ~Week 56 familiarization; serious from Week 71):** ETS Practice Test 1/2 and official-style materials for the **2026 iBT** task types only.
- **AWL:** Academic Word List for C1+ productive use (see checklist).

## 2026 TOEFL iBT task alignment (Week 71+)

**Do not practice retired formats** (old 4-task Speaking; Integrated/Independent essays).

- **Reading:** Complete the Words; Daily Life; Academic Passage
- **Listening:** Choose a Response; Conversation; Announcement; Academic Talk
- **Writing:** Build a Sentence; Email; Academic Discussion
- **Speaking:** Listen and Repeat; Interview

## Gates

See `07-master-checklist.md`. Rough rule: do not skip a gate week; collect evidence (recording + writing) and an honest yes/no.

## Scoring note (honest)

- TOEFL iBT section reporting uses a **1–6** band-style scale (not the legacy 0–120 total as your daily target number).
- **Peak phase target:** secure about **5.5** with stable timing and process, then **stretch toward 6**.
- Treating “120” as a casual synonym for perfection is fine motivationally, but pedagogically **band 6 is a stretch**.
