# Master Checklist — Gates, AWL, Resources

## Progression gates (must collect evidence)

### Gate A1 — Week 10
- [ ] Introduce yourself and describe daily routine (60–90 sec voice memo)
- [ ] Write 60–80 words in present + past (regular) with ≤3 major errors
- [ ] Recognize 300+ high-frequency words receptively
- [ ] Checkpoint Days 5–6 marked Yes

### Gate A2 — Week 22
- [ ] 90–120 sec talk: past trip + future plan + advice
- [ ] Write 120–150 words using connectors and present perfect at least once
- [ ] Can use going to / will / should / first conditional in speech
- [ ] Portfolio samples saved

### Gate B1 — Week 40
- [ ] 2–3 min monologue with discourse markers
- [ ] Write 180 words: clear paragraph structure
- [ ] Follow a short academic-style paragraph and summarize orally
- [ ] Listening: gist + 5 details from one recording

### Gate B2 — Week 58
- [ ] 3–4 min interview answers with hedges and examples
- [ ] Write 220–250 words semi-formal OR email + discussion sample
- [ ] Read a long article and give oral précis
- [ ] Light TOEFL familiarization complete (no full test required)

### Gate C1 — Week 78
- [ ] Academic Discussion + Email timed samples meet task fulfillment
- [ ] Listen and Repeat intelligibility self-score ≥5 on familiar strings
- [ ] Interview answers organized and concrete
- [ ] Diagnostic across 2026 task types logged
- [ ] Honest plan: secure 5.5 then stretch to 6

### Gate C2 / Peak — Week 100
- [ ] Two full-section simulation cycles reviewed (Practice Test style)
- [ ] Top leaks closed or consciously managed
- [ ] Test-day logistics script written
- [ ] Taper completed (no heavy cramming Day 6 Week 100)

## AWL note

From **Week 60**, treat Academic Word List items as **productive** targets:
- Add to Anki with collocations (not translations alone).
- Force use in Academic Discussion and oral summaries.
- Track receptive → productive upgrades weekly.

## Resource list (types)

| Type | Use |
|------|-----|
| CEFR coursebook | Parallel grammar/vocab to each week |
| Anki | Daily SRS; tags WeekW-DayD |
| Graded readers | Fluency & vocab recycling |
| Dictionary (EN–EN) | From B1 onward |
| Pronunciation drills | Minimal pairs; shadowing; L&R |
| ETS Practice Test 1/2 | Peak simulations (2026 format) |
| Error log (spreadsheet) | Form / meaning / pronunciation / timing |
| Portfolio folder | Writings + voice memos + gate artifacts |

## Optional stretch — Weeks 101–110 (brief; not full daily cards)

Use only if post-100 scores need polish:

- **101–102:** Reading leaks only (Complete the Words + Academic Passage).
- **103–104:** Listening endurance (Conversation + Academic Talk).
- **105–106:** Writing triad precision (zero careless errors).
- **107–108:** Speaking intelligibility + Interview density.
- **109:** Mixed light simulation.
- **110:** Final taper + exam.

Do **not** add new grammar systems; only stabilize process and timing.

## Weekly self-audit (every Day 6)

- [ ] 6 day cards completed this week
- [ ] Anki due ≤ backlog of 1 day
- [ ] At least 4 voice memos saved
- [ ] At least 4 writing samples saved
- [ ] Top 3 errors identified for next week
